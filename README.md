## ✨ Overview

Smart Invigilator is an AI-powered exam monitoring system that automatically detects suspicious activities during examinations using a webcam or CCTV feed.

### 🚀 Features

- 📹 Real-time monitoring
- 📱 Mobile phone detection
- 👥 Multiple person detection
- 👀 Head movement analysis
- 🚨 Alert generation
- 🌐 Flask web dashboard

---

## 🛠️ Tech Stack

- **Python**
- **Flask**
- **YOLO**
- **PyTorch**
- **OpenCV**
- **HTML, CSS, JavaScript**

---

## 🏗️ Architecture

Camera → OpenCV → YOLO/PyTorch → Alert Engine → Flask Dashboard

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/Smart-Invigilator.git
cd Smart-Invigilator
```

### Create virtual environment

```bash
python -m venv venv
```

### Activate it

**Windows**

```bash
venv\Scripts\activate
```

**Linux/macOS**

```bash
source venv/bin/activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
